# Digital Dost Website

Static HTML, CSS, and JavaScript website for Digital Dost digital marketing agency.

## Run locally

```bash
python -m http.server 8080
```

Open in browser: http://localhost:8080/

## Main pages

- Home
- About Us
- Blog
- Contact
- SMMA
- SEO
- Advertising Agency
- Blog posts

## Project notes

- Blog comments use `assets/js/local-comments.js` (browser localStorage)
- SEO files: `robots.txt`, `sitemap.xml`
